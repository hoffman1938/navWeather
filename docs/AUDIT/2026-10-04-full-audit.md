## 6. Cloudflare: Pages или Workers

Факты (официальная таблица Cloudflare «Pages → Workers», проверено 2026-10-04): на Pages **нет** Cron Triggers, Queue
consumers, **привязки Rate Limiting**, Workers Logs, Cloudflare Vite plugin; Durable Objects — только через отдельный Worker.

Что это значит для navWeather сегодня:

| | Workers (ADR-016, как сейчас в `wrangler.toml`) | Pages |
| --- | --- | --- |
| Приложение (статика) | да | да |
| `/api/v1/*` | тот же Worker | Pages Functions (перенос кода) |
| Живая геопозиция, сообщения водителей (2 Durable Objects) | да | только второй, отдельный Worker + привязка к нему |
| Лимиты частоты (4 привязки) | да | **нет** — API без защиты от злоупотреблений |
| Cron, очереди, логи (этапы 3–10 плана) | да | нет |
| Свой домен позже | да | да |
| Деплой сейчас | `npm run build && npx wrangler deploy` (готово) | нужен перенос |

**Рекомендация:** Workers, как решено в ADR-016: деплой уже готов и бесплатен (Workers Free), домен подключается так же, как
к Pages. Если «Pages» в задаче означает «бесплатный хостинг Cloudflare со своим доменом», это и есть Workers со static assets.
