## 0. Кратко

- **Цель:** навигация масштаба Google Maps, полностью бесплатная для пользователей, в которой **ни один сторонний
  сервис не стоит денег**. Владелец оплачивает **только хостинг** (серверы, трафик, хранилище). Спонсоров, грантов и
  кредитов нет.
- **Главный вывод аудита:** сейчас в навигации нет ни одного платного сервиса, но *все* используемые сейчас
  публичные серверы имеют лимиты или запрещают использование в продакшене (§2.4) — **поэтому все они из навигации
  убираются.** Софт, на котором они работают, — бесплатный open source, а данные — открытые.
- **Правило «всегда бесплатно» (§1.1):** сторонний компонент допустим, только если он бесплатен **всегда и при любом
  числе пользователей** — свой экземпляр свободного софта, открытые файлы данных или сервис без лимитов и без
  платного тарифа. Ничего «бесплатного до лимита», «бесплатного до продакшена» или «бесплатного на пробном
  тарифе» в плане нет.
- **Принцип перехода:** «тот же софт — на своём хостинге». Valhalla вместо демо-OSRM, свой Photon вместо
  Nominatim/Photon, своя база мест (OSM + Overture + Foursquare OS Places) вместо Overpass, свой Open-Meteo вместо
  Open-Meteo API, свой MOTIS вместо Transitous, свои тайлы (OpenFreeMap остаётся резервом), свой бэкенд реального
  времени вместо Workers Free. Сторонних лимитов не остаётся, платить сторонним сервисам не нужно — ни сейчас, ни потом.
- **Разработка — за $0:** весь стек запускается локально в Docker на выгрузке региона (Грузия), CI — GitHub Actions
  для открытого репозитория (бесплатно без лимита минут). Хостинг оплачивается только с момента запуска для
  пользователей.
- **Недостающие функции Google Maps** закрываются бесплатными данными и софтом (§5): спутник, рельеф, радар,
  панорамы улиц, отзывы, фото, Plus Codes, зарядки, официальные предупреждения, объезды платных дорог, грузовики и
  мотоциклы, оптимизация остановок, изохроны, прокат, офлайн-карты, **пробки — свой краудсорсинг**. Без бесплатного
  источника остаются: загруженность мест, бронирования и цены отелей, цены платных дорог, Immersive View/AR,
  спутник детальнее 10 м по всему миру.
- **Объём:** 9 этапов (0–8), ≈ 70 задач, ≈ 235–240 рабочих дней для одного инженера (≈ 4–5 месяцев для команды из трёх).
  Этап 1 из PRODUCTION_READINESS_PLAN (безопасность водителя, B-01…B-07) выполняется **первым** и не меняется.

## 1. Правила (решение владельца, 2026-10-04)

1. **Бесплатно для пользователей и некоммерчески:** без подписок, рекламы и платных функций (сохраняется из ADR-014).
2. **Никаких платных сервисов:** ни ключей на платных тарифах, ни оплаты за запрос или пользователя, ни платных
   данных. Сторонние компоненты — только **свободный софт** и **открытые данные**.
3. **Никаких спонсоров:** не рассчитываем на Cloudflare Project Alexandria, Fastly Fast Forward, AWS Open Data
   Sponsorship, гранты и кредиты.
4. **Оплачивается только хостинг:** вычисления, хранилище, трафик, CDN перед нашими серверами, домен.
5. **Масштаб уровня Google Maps:** архитектура растёт добавлением хостинга, без переписывания и без новых
   сторонних договоров.
6. **Все сторонние API и данные бесплатны всегда** — и в разработке, и в продакшене, при любом числе пользователей
   (§1.1). Публичные демо-серверы с лимитами не используются нигде, в том числе в разработке: разработка идёт на
   том же своём стеке, запущенном локально.
7. **Разработка не требует денег:** локальный Docker, открытые выгрузки региона, GitHub Actions для открытого
   репозитория. Деньги (только на хостинг) нужны с момента запуска для пользователей.

### 1.1 Правило «всегда бесплатно»: что допустимо, а что нет

Допустимы только три класса сторонних зависимостей — их стоимость для нас равна нулю всегда, при любом масштабе:

| Класс | Что это | Почему всегда бесплатно | Примеры |
| --- | --- | --- | --- |
| **A. Свой экземпляр свободного софта** | программа с открытой лицензией, работающая на нашем хостинге | лицензия бесплатна навсегда; за запросы пользователей никто, кроме хостинга, денег не берёт | Valhalla, Photon, Open-Meteo, MOTIS, PostGIS, Planetiler, LibreWXR, Kokoro |
| **B. Открытые файлы данных** | наборы данных под открытой лицензией, которые наш конвейер скачивает по расписанию | объём загрузок **постоянный** (раз в неделю / раз в прогон модели) и не растёт с числом пользователей; платного тарифа у этих данных нет | выгрузки OSM, Overture, Foursquare OS Places, дампы Open Charge Map и Wikidata, файлы моделей ECMWF/DWD/NOAA, Copernicus DEM и Sentinel-2, GTFS, Natural Earth, DB-IP Lite, файлы NASA FIRMS, цены топлива Франции и Испании |
| **C. Сервис без лимитов и без платного тарифа** | публичный сервис, условия которого прямо разрешают неограниченное использование | лимита, после которого надо платить, не существует | OpenFreeMap (резерв тайлов); возможности самого браузера (Web Speech, голоса, Web Push) |

**Недопустимо** (не используется нигде — ни в разработке, ни в продакшене):
- «бесплатный уровень» с лимитом запросов, после которого нужен платный тариф или договор;
- ключи с квотами (дневными, по запросам, по объёму), «бесплатно до N пользователей», пробные периоды;
- сервисы, запрещающие использование в продакшене или для приложений (демо-серверы OSRM/FOSSGIS/Valhalla, Nominatim,
  Photon komoot, Overpass, Open-Meteo API, Transitous, MET Norway, RainViewer, Mapillary API, Tankerkönig и т. п.);
- зависимость, объём обращений к которой растёт вместе с числом пользователей и не находится на нашем хостинге.

Проверка: ворота **G2'** и **G3'** (§8) — E2E-тест собранного приложения фиксирует, что сетевые запросы уходят только
на наши домены и к сервисам класса C; конвейеры данных обращаются только к источникам класса B.

## 3. Принцип: тот же софт — на своём хостинге

Каждый публичный сервис выше — это экземпляр свободного софта с открытыми данными. Запуская тот же софт у себя,
мы получаем ту же функцию без лимитов и без оплаты третьим лицам; растёт только счёт за хостинг, и он растёт
предсказуемо. Правила проектирования:

- **Сервер-движок без состояния** (stateless) за балансировщиком, несколько регионов, горизонтальное масштабирование.
- **Кэшируемые ответы:** погода — по ячейке сетки и прогону модели; места — по тайлу; тайлы карты — неизменяемые
  файлы за CDN; геокодинг — по нормализованному запросу. Маршруты кэшируются слабо — под них основная вычислительная
  мощность.
- **Сначала офлайн, где можно:** пакеты регионов (тайлы, места) снижают повторный трафик — главный пункт счёта.
  Для оценки: у Organic Maps средний пользователь скачивает ≈ 500 МБ карт в месяц.
- **Конфигурация, а не переписывание:** клиент уже работает через интерфейсы провайдеров (`src/services/providers.ts`);
  смена провайдера = новый адаптер + переменная `VITE_*`. Контракты `/api/v1` сохраняются (ADR-009).

## 5. Функции Google Maps: что есть, чего нет, откуда взять бесплатно

### 5.1 Уже есть в навигации
Поиск и карточка места, маршрут с альтернативами, пошаговая навигация с полосами и голосом, ограничения скорости и

- Immersive View, Live View (AR), спутник детальнее 10 м по всему миру.
- Картинки развязок как у Google (только схемы).
- Нативные iOS и CarPlay без платного аккаунта Apple; Android Auto — только через Google Play (платный аккаунт).

(второй/третий инженер): этап 1; FS-2.4…FS-2.9 с соответствующими FS-3.x; этап 5. Хостинг (FS-0.3, D2) нужен только
для запуска для пользователей — до этого вся разработка и тестирование стоят $0.

**Итого:** ≈ 3 (этап 0) + 8 (этап 1) + 52 (этап 2) + 17 (этап 3) + 30 (этап 4) + 38 (этап 5) + 44 (этап 6) + 25
(этап 7) + 20 (этап 8) ≈ **237 рабочих дней** для одного инженера; ≈ 4–5 месяцев для команды из трёх. Оценки
грубые; уточняются после пилота (FS-2.11).

## 9. Риски

| Риск | Вероятность | Влияние | Мера |
| --- | --- | --- | --- |
| Стоимость хостинга растёт быстрее аудитории | средняя | деньги владельца | кэш-слои, офлайн-пакеты, регионы по мере запуска, ежемесячный отчёт (FS-8.5) |
| Сложность эксплуатации своих движков | высокая | отказы | IaC, наблюдаемость, runbooks, staging, учения (FS-2.10, FS-8.x) |
| Качество данных мест (дубли, устаревание) | средняя | доверие | склейка, приоритет источников, правки через OSM Notes, отзывы |
| Пробки плохого качества при малом числе пользователей | высокая на старте | ETA | показывать «нет данных» вместо выдумки; открытые фиды где есть |
| Лицензионные ошибки (ODbL share-alike, AGPL, NC) | средняя | юридические | LICENSING_MATRIX до использования, ворота G13 |
| Приватность при сборе скоростей | средняя | доверие, право | ADR-017, агрегация на устройстве, без траекторий, опт-ин |
| Нет радара для Кавказа | высокая | функция | честная подпись «оценка модели» |
| OpenFreeMap изменит условия | низкая | резерв тайлов | основной — свои тайлы |
| Источник открытых данных (класс B) изменит условия или исчезнет | низкая–средняя | обновления данных | уже скачанные данные остаются у нас по их лицензии; зеркала и альтернативные источники (planet.openstreetmap.org ↔ Geofabrik, ECMWF ↔ DWD ↔ NOAA, Overture ↔ Foursquare); правило §1.1 — источник с появившимся лимитом или платой отключается |
| Соблазн «временно» подключить сервис с бесплатным лимитом | средняя | нарушение правила владельца | ворота G2'/G3' и тест на бандл (FS-3.1) не пропускают такую сборку |
| Нативные iOS/CarPlay недоступны | высокая | охват | PWA; Android через F-Droid; решение D7 |
