# IMPLEMENTATION ROADMAP — navWeather (после аудита 2026-10-03)

> Основа: [MASTER_AUDIT.md](MASTER_AUDIT.md) · [FEATURE_GAP_ANALYSIS.md](FEATURE_GAP_ANALYSIS.md).
> Сложность: S — дни · M — 1–3 недели · L — 1–2 месяца · XL — квартал+ (один опытный инженер).
> Требования и их статусы: [docs/PROJECT_REQUIREMENTS.md](../PROJECT_REQUIREMENTS.md).

## Почему фазы отличаются от исходного шаблона

Исходный шаблон предполагал: стабилизация навигации → погода вдоль маршрута → прогноз и алерты → Long Trip → …
Аудит показал, что **погода вдоль маршрута и предупреждения уже работают** (проверено вживую). Поэтому:

- фазы «Weather along route» и «Weather prediction + alerts» сведены в **Phase 2 — укрепление погодного движка**
  (пороги, горизонт, кэш, новые типы рисков);
- самые опасные дефекты находятся в **Long Trip** (топливо, перепланирование) — они идут первыми, в **Phase 0**;
- «Accommodation / fuel / rest» объединены с завершением Long Trip (**Phase 4**): база уже есть;
- собственный роутер вынесен в отдельную фазу (**Phase 5**): он разблокирует избегание платных дорог, кратчайший
  маршрут, перекрытия, профили ТС и Truck Mode;
- до публичного запуска обязательна **Phase 1 — соответствие условиям провайдеров и эксплуатация**.

## Правило для каждой задачи (AGENTS.md)

1. Прочитать `PROJECT_REQUIREMENTS.md`, связанные ADR и спецификацию функции. 2. Изучить текущий код и тесты.
3. Записать CURRENT → TARGET → GAP. 4. План. 5. Реализация. 6. Тесты (сначала регрессионный тест,
воспроизводящий дефект). 7. Обновить статус требования и документацию в том же коммите.
Не переписывать работающие системы; не менять контракты `/api/v1` без анализа (ADR-009) — только аддитивно.

## PHASE 8 — Truck Mode (L, после Phase 5)

Профиль ТС (высота, ширина, длина, масса, оси, прицеп, ADR) → Valhalla truck costing; стоянки грузовиков, HGV-АЗС
уже ранжируются. **Не считать готовым**, пока роутер не учитывает параметры (VH-02). Юридические нормы вождения —
только с проверенными официальными источниками по юрисдикции (LT-18).

## PHASE 9 — Fleet / B2B (отложено)

Предпосылки: аккаунты, коммерческие лицензии всех провайдеров (Open-Meteo платно, свой роутер, без Transitous или
с договором), наблюдаемость, SLA. Тот же движок `src/trip` на сервере. **Не начинать до завершения Phase 5.**
