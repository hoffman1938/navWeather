## 0. Кратко

- **Откуда стартуем:** поздняя альфа (v0.1.0). Ядро — погода на ETA каждой точки маршрута — работает; есть навигация,
  режимы передвижения, Long Trip, живая геопозиция, сообщения водителей. Не развёрнуто ни разу; 7 дефектов
  безопасности водителя (B-01…B-07); все внешние сервисы — публичные бесплатные серверы с лимитами.
- **Куда идём:** навигация масштаба Google Maps, бесплатная для пользователей, где **всё стороннее бесплатно всегда**
  (свой экземпляр свободного софта, открытые файлы данных или сервисы без лимитов), а **единственная трата —
  хостинг на Cloudflare** (Workers + R2 + D1 + Durable Objects + Queues + Cron + Containers).
- **Два обязательных режима работы:** каждая функция работает и на **localhost** (без аккаунта и без денег), и на
  **тестовом Worker** (`*.workers.dev`), а позже — на своём домене. Один и тот же набор E2E-тестов проходит в обоих.
- **Объём:** 14 этапов (0–13) + необязательный 14-й, ≈ 110 задач, ≈ 277 рабочих дней для одного инженера
  (≈ 5–6 месяцев для команды из трёх). Первые деньги (Workers Paid, $5/мес + использование) нужны на этапе 5,
  когда первый движок уходит в Containers; до этого — $0.

## 1. Принципы (обязательны для каждой задачи)

1. **Безопасность водителя — первой** (этап 1 до любых новых функций).
2. **Всё стороннее — бесплатно всегда** ([FREE_STACK_PLAN §1.1](FREE_STACK_PLAN.md)): класс A (свой экземпляр
   свободного софта), B (открытые файлы данных по расписанию), C (сервис без лимитов и без платного тарифа). Никаких
   «бесплатных уровней с лимитом», ключей с квотами, пробных периодов и публичных демо-серверов — даже в разработке.
3. **Хостинг — только Cloudflare, на Workers (не Pages)** (ADR-016).
4. **Паритет localhost ↔ Workers:** задача не закрыта, пока она не проверена в обоих режимах (колонки «Локально» и
   «Workers» в таблицах ниже).
5. **Регионы по очереди:** Грузия → Кавказ → Турция/Европа → мир. Данные, движки и проверки — сначала для региона.
6. **Только реальные данные:** нет источника — «недоступно»; симуляция подписана; сообщения водителей — «сообщают».
7. **Приватность:** никакой истории перемещений на сервере; в логах нет координат.
8. **Протокол [AGENTS.md](../AGENTS.md):** требования → текущий код → CURRENT/TARGET/GAP → **сначала регрессионный
   тест** → код → тесты → статусы требований и документация в том же коммите.

## 2. Окружения и паритет localhost ↔ Workers

| | **local** (localhost) | **preview** (тестовый Worker) | **production** |
| --- | --- | --- | --- |
| Адрес | `http://localhost:5173` | `https://navweather-preview.<аккаунт>.workers.dev` | `*.workers.dev`, затем свой домен |
| Приложение + API | `npm run dev`: Vite + Cloudflare Vite plugin — Worker в workerd с локальными DO, D1, R2, Queues | `wrangler deploy --env preview` (тот же бандл) | `wrangler deploy --env production` |
| Durable Objects, D1, R2 | эмуляция в `.wrangler/state` | отдельные preview-ресурсы | боевые ресурсы |
| Движки (Valhalla, MOTIS, LibreWXR, Photon) | те же образы в Docker (`vite dev` / `wrangler dev` запускают Containers локально) | Cloudflare Containers | Cloudflare Containers по регионам |
| Данные региона | `npm run seed:local` (конвейер пишет в локальные D1/R2) | `npm run seed:preview` / задача в CI | конвейеры по расписанию |
| Cron / очереди | вызов вручную (тестовый эндпоинт расписания) | Cron Triggers / Queues | Cron Triggers / Queues |
| Секреты | `.dev.vars` (в git не попадает) | `wrangler secret put --env preview` | `wrangler secret put --env production` |
| Конфигурация клиента | `.env.development` | `.env.preview` | `.env.production` |
| Тарифный план | не нужен | Workers Free → Workers Paid с этапа 5 | Workers Paid |
| Проверка | `npm test`, `npm run e2e` (BASE_URL=localhost) | `npm run e2e` (BASE_URL=preview) | smoke после деплоя |

**Правила паритета:**
- Один код и одни образы для всех окружений; различаются только переменные и привязки (`wrangler.toml [env.*]`).
- Нельзя писать код, который работает только на Cloudflare (например, полагается на `request.cf` без локальной
  заглушки) или только локально (например, читает файлы с диска вместо R2).
- Локальной разработке не нужен ни аккаунт Cloudflare, ни интернет для API (кроме загрузки открытых данных в seed).
- Нужен Docker (Docker Desktop или Colima) — для движков; без них приложение работает, а функции движков честно
  «недоступны локально».

## 4. Целевая архитектура на Cloudflare

```
                       PWA (React + MapLibre) · движки в TS · голос и распознавание на устройстве
                                              │ HTTPS / WebSocket — только наш домен
 ┌────────────────────────────────── Cloudflare (один Worker-проект) ─────────────────────────────────┐
 │ Static assets: приложение, малые наборы тайлов региона, границы       (бесплатно, без лимита)      │
 │ Worker /api/v1/*: лимиты, валидация, кэш (Cache API на своём домене)                               │
 │   ├─ R2: PMTiles карты, тайлы мест, ячейки прогноза, рельеф, спутник, снимки данных                │
 │   ├─ D1 (по регионам): индекс мест, геокодер FTS5, аккаунты, списки                                │
 │   ├─ Durable Objects: live-шаринг, сообщения водителей (шарды по geohash), агрегаты пробок         │
 │   ├─ Queues: push-рассылки, приём скоростей для пробок                                              │
 │   ├─ Cron Triggers: обновление данных, прогнозов, очистка                                           │
 │   └─ Containers (по регионам): Valhalla · MOTIS · LibreWXR · (Photon)                               │
 └────────────────────────────────────────────────────────────────────────────────────────────────────┘
 Конвейеры: открытые данные (OSM/Geofabrik, Overture, Foursquare OS Places, Open Charge Map, ECMWF/DWD/NOAA,
 Copernicus, GTFS, Natural Earth) → Container-задачи / GitHub Actions (открытый репозиторий) → R2 / D1 / образы
 Резерв тайлов: OpenFreeMap (класс C)
```

Подробное соответствие «компонент → сервис Cloudflare → локальный аналог» — в [FREE_STACK_PLAN §6a](FREE_STACK_PLAN.md).

## 8. Риски

| Риск | Вероятность | Влияние | Мера |
| --- | --- | --- | --- |
| Лимиты Containers (12 ГБ / 20 ГБ на экземпляр, 1 500 vCPU на аккаунт) не позволят движки на весь мир | средняя–высокая при глобальном масштабе | маршруты/поиск за пределами регионов | шардирование по регионам; пилот DP-5.6; при «не хватает» — ADR о вынесении движков на арендованные серверы (тоже хостинг) |
| Стоимость хостинга растёт быстрее аудитории | средняя | деньги владельца | R2 без платы за трафик, кэш на домене, статика бесплатна, офлайн-пакеты, ежемесячный отчёт |
| Холодные старты контейнеров (1–3 с) | средняя | задержка первого маршрута | минимальное число тёплых экземпляров в регионах с трафиком; учёт в пилоте |
| Эфемерный диск контейнеров | высокая | большие образы, долгие старты | данные запекаются в образ или читаются из R2; регионы малыми частями |
| Расхождение localhost и Workers | средняя | «у меня работает» | правила §2, ворота G4, одни образы |
| Качество геокодера на D1 FTS5 | средняя | поиск хуже Photon | решение D10 по контрольным запросам; Photon в контейнере (DP-5.7) |
| Источник открытых данных изменит условия или исчезнет | низкая–средняя | обновления | зеркала и альтернативы; скачанное остаётся по лицензии; правило §1.1 |
| Соблазн «временно» подключить сервис с лимитом | средняя | нарушение правила владельца | ворота G2/G3, тест на бандл |
| Сложность эксплуатации | высокая | отказы | IaC, наблюдаемость, runbooks, preview, учения |
| Пробки плохого качества при малом числе пользователей | высокая на старте | ETA | честное «нет данных»; открытые фиды |
| Приватность при сборе скоростей | средняя | доверие, право | ADR-017, без траекторий, опт-ин |
| Нет радара для Кавказа | высокая | функция | подпись «оценка модели» |
| Нативные iOS/CarPlay недоступны | высокая | охват | PWA; Android через F-Droid |

## 11. Как поддерживать этот план
- Закрыл задачу → отметка в таблице этапа, статус требования в PROJECT_REQUIREMENTS, документация — в том же коммите.
- Новая работа → новая строка `DP-<этап>.<n>`; ничего не удаляется, отменённое помечается «отменено» с причиной.
- Условия источников данных и лимиты Cloudflare перепроверяются раз в квартал.
